MidnightZone
MidnightZone is a cinematic notification addon for **World of Warcraft:
Midnight 12.1**.

It replaces ordinary area text and expands notifications for
exploration, quests, objectives, achievements, scenarios, delves, and
important events into a customizable Midnight-style presentation.

Features
-   Zone, subzone, and first-discovery notifications
-   Quest and World Quest notifications
-   Scenario, delve, and objective updates
-   Level-up, achievement, and boss notifications
-   Smart grouped summaries
-   Priority queue, duplicate protection, and transition filtering
-   Notification History and repeat-last support
-   Persistent Live Preview
-   Midnight and dynamic Class Color themes
-   Configurable fonts, colors, frames, icons, and animations
-   Animation presets
-   Global display time and per-type hold times
-   Per-type sounds with direct Sound Preview
-   Optional LibSharedMedia integration
-   Profiles
-   Runtime Diagnostics

Commands
-   `/mz` or `/midnightzone` --- Open settings
-   `/mz test` --- Test a zone notification
-   `/mz group` --- Test a grouped quest summary
-   `/mz repeat` --- Replay the latest notification
-   `/mz move` --- Toggle move mode
-   `/mz custom Title|Subtitle|Third` --- Show a custom notification

Installation
1.  Download the release archive.
2.  Extract the `MidnightZone` folder into
    `World of Warcraft/_retail_/Interface/AddOns/`.
3.  Start or reload World of Warcraft.
4.  Use `/mz` to open the configuration.

SharedMedia
LibSharedMedia/SharedMedia is optional. If available, MidnightZone can
use additional registered fonts, sounds, and media. Without it, built-in
and Blizzard fallbacks are used.

Compatibility
-   World of Warcraft: Midnight 12.1
-   Interface: 120100
